# Robotism

Collection of a few important robotics methods:
- Force Distributor: For balancing a robot between several contact points such as multiple legs that also have feet with non-zero surface area (add contact points to model the feet as a convex hull), it is based on Sang Ho Hyon's method from Ritsumeikan University.
- Kalman Filter for calculating Velocity and Acceleration from position encoders: Robot's typically sense the position of their joints using position encoders. However velocity and acceleration signals are necessary in many control methods such as the disturbance observer. Naively one may calculate the velocity & acceleration using a finite difference of encoder reading at different time stamps, but the problem is that the encoders position readings are themselves quantized and taking the time derivative of this quantization creates a lot of noise, even more so for the double derivative (acceleration). The Kalman filter greatley reduces such noise by adding a dynamic model of the motor while explicitly treating the position encoder data with uncertainty. The overall effect are much smoother velocity & acceleration curve without the slow response of a heavy low pass filter.
- Quadratic Programming Trajectory Generation: This is important for making the Center-of-Mass (COM) follow a desired trajectory (such as a path from foot-to-foot as it walks) but subjected to the constraint that the robot must not fall while walking. This constraint can be satisfied for a constant COM height robot by limiting the acceleration of the COM so that the robot's Zero-Moment-Point (ZMP) stays within the convex hull of the support area created by the feet. Quadratic Programming allows us to formulate this problem as a constrained minimization and the provided solver is then able to output a COM trajectory.
